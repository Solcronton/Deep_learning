# Artificial Neural Network (ANN)

## 📌 Overview

This project implements an **Artificial Neural Network (ANN)** using Python and Machine Learning libraries.

An ANN is a machine learning model inspired by the human brain. It consists of interconnected **neurons** arranged in layers and can be used for classification and prediction tasks.

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn
* TensorFlow / Keras

## 🧠 ANN Architecture

The neural network consists of:

1. **Input Layer** – Takes the input features.
2. **Hidden Layers** – Learn patterns from the data.
3. **Output Layer** – Produces the final prediction.

Example:

```text
Input Layer
     ↓
Hidden Layer
     ↓
Hidden Layer
     ↓
Output Layer
```

## 📊 Model Evaluation

The model can be evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix
